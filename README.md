# GammaApp - Real-Time Communication & AI Super App 🚀

GammaApp is a cross-platform mobile application that combines seamless text chat, video/voice calling,  and a smart AI assistant powered by Meta's Llama 3. 

## ✨ Key Features
* **WebRTC Video & Voice Calls:** High-quality, real-time calling integrated with ZegoCloud.
* **Meta AI Assistant:** Chatbot integration using the Groq API (Llama 3) with real-time markdown rendering.
* **Background Notifications:** Firebase Cloud Messaging (FCM) wakes the app for incoming calls even when terminated.
* **Secure Auth & Database:** User management and real-time chat powered by Firebase Auth and Cloud Firestore.
